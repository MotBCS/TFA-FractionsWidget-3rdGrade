# Fractions Widget - 3rdGrade

Grade Level: 3rd
Subject Area: Math

# Objective:
Comparing Fractions with the Same Denominator
Students will be able to compare two fractions with the same denominator using visual models and the symbols >, <, =.

Key Idea: When the denominators are the same, compare the numerators. The fraction with the greater numerator is the greater fraction (bigger)
